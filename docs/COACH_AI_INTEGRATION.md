# Coach AI 接入说明

当前 Coach 只请求 FORGE 服务端代理：`POST /v1/coach/messages`。模型供应商、模型名称和 API Key 都由服务端管理，客户端不读取供应商密钥。

客户端只需要公开的 FORGE 服务端地址；模型供应商密钥、鉴权密钥和服务端配置必须保留在 API 服务端，不能放入 Expo 公共环境。修改 `.env.local` 后需要重启 Expo Metro：

```bash
pnpm start -c
```

环境变量：

```text
EXPO_PUBLIC_FORGE_API_URL=https://api.example.com
EXPO_PUBLIC_COACH_AI_TIMEOUT_MS=30000
```

## 当前行为

Coach 会把用户目标、今日训练、准备度、睡眠/疲劳/酸痛、营养摄入和食物池摘要发给模型。模型返回回答和受限的 Action 意图（加入食物、应用饮食方案、应用训练建议）；页面只接受白名单 Action，仍然要求用户点击确认，确认后才调用本地状态变更。

所有会改数据的 Action 都有撤销路径。模型即使返回了“已经加入/已经应用”之类的完成性表述，页面也会在本地安全层拦截，并改成确认文案，避免模型越过用户确认直接改变状态。

模型请求失败时，Coach 会显示真实错误并提供重试/取消，不会回退到本地编造回答。未登录或服务端地址未配置时不会声称 AI 已连接。Web 预览可能受跨域策略影响，真实 Expo Go 原生运行更适合验证接口连通性。

## 安全边界

`EXPO_PUBLIC_FORGE_API_URL` 只是公开的服务端地址。正式上线前必须部署该服务端，并完成用户鉴权、会话过期、限流、日志脱敏、成本保护和数据删除流程。
